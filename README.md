# 软件能力认证证书管理台

集团管理人员可在浏览器中汇总软件能力认证证书、批量标记发放状态和按部门导出。员工数据在本机处理，下载的完整 Excel 工作簿保存本次结果。

## 本地运行

使用 Node.js 22.12 或更高版本，在项目目录运行：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，点击「试用样例」和「开始汇总」，即可核对 10 条样例证书。也可以拖入自己的 `.xlsx` 文件。首次输入的 00 工作表可以完全空白。下载完整工作簿后，下次导入可继承同一证书的发放状态和生成时间。

重新导入已有汇总记录的工作簿后，点击「查看变更」，可对照原 00 表查看新增、移出和获得日期调整的证书，并筛选原已发放的记录。

导入后可进入「数据台账」查看 00–03 表。使用表头下的输入框组合筛选各列，或点击表头切换升降序。行号对应原工作表位置。完成汇总后，00 台账显示本次结果，包括页面内的发放标记。

收到客户的完整新版时，可在首页点击「换版核对」。同时选择上次正式汇总和本次客户工作簿，预览 01、02 来源变化、03 规则变化及 00 证书影响。确认两次供数范围一致后，下载以本次工作簿为底稿的汇总结果。

## 构建与验收

```sh
npm test
npm run build
npm run preview
```

将 `dist/` 的内容放在内网静态网站根目录即可使用。页面、图标、Excel 处理库和虚构样例均随构建产物提供。转换在单个 Web Worker 中执行。

回归测试用仓库中的输入和预期工作簿核对首次汇总、增量重算、部门筛选、日期系统与工号前导零。样例的固定生成时间仅用于测试，页面汇总取实际运行时间。
